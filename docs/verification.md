# 验证记录

下表记录已完成的检查，不是所有环境的兼容性保证。公开记录只包含合成测试的范围和结论，不附机器标识、私人路径、会话日志或凭据。

## 2026-10-25：1.1.1 工具结果映射

环境：Linux、QwenPaw 2.2.2.post1、DSH 0.2.1-rc.2，插件 1.1.1、桥 1.1.0。

- 272 项离线测试通过，0 跳过；安装包与发布源码逐成员匹配。
- 插件通过宿主热加载，安装文件与正式 ZIP 一致。
- 一次真实模型请求读取合成临时文件，提示词不包含文件中的随机标记。
- 运行期收到唯一 read 工具的开始及完成事件；完成事件直接带回 182 字符文本，并包含随机标记，最终回答与文件内容匹配。
- 测试文件未变化，未观测到其他工具或提权请求。探针使用 read-only 和拒绝提权的审批端口。

这是工具文本投影的集成验证，不依赖事后会话日志补齐输出。它不代表 read-only 实现了文件读取白名单；该模式限制修改，但不限制全部读取范围。

## 2026-10-25：1.1.0 基础链路

相同 Linux 宿主与 DSH 版本，插件和桥均为 1.1.0。

| 项目 | 路径 | 结果 |
|---|---|---|
| 简短回答 | 现役 QwenPaw HTTP API | 返回 PONG，正常完成，未观测到工具调用 |
| 实时文本 | 已安装适配器 → ACP | 回答以多个增量块到达，而非回合末一次投递 |
| 并发隔离 | 一个适配器、同连接两个会话 | 回答各含自己的标记，未串入另一个会话，均正常结束 |
| 取消与后续使用 | 已安装适配器 → ACP | 发送取消通知，消费者退出，随后同会话请求正常完成 |
| 跨进程恢复 | 新适配器进程、原会话映射 | 恢复后能回答先前对话的合成主题 |
| 文件读取 | 已安装适配器 → ACP | read 返回合成文件内容；当时宿主完成事件文本丢失，随后由 1.1.1 修复 |

HTTP API 的 PONG 使用智能体既有权限设置；独立适配器测试使用 read-only。不同测试路径不能混作同一种权限验收。取消测试确认了通知、消费者退出与恢复可用，未测量 provider 计费何时停止。

1.1.0 原始发布阶段的离线范围为 Python 252 项、桥 Node 39 项、helper 32 项、原子写 6 项、runner 自测 5 项。1.1.1 新增了 20 项映射测试；历史数字不随新版本改写。
